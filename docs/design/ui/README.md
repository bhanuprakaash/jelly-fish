# UI prototypes

Design canvas sources for [../ui.md](../ui.md). Each `*.dc.html` file is one artboard; `canvas.json` places them on the canvas. They need the canvas runtime (`support.js`) to render, so open the published canvas rather than these files in a browser: https://claude.ai/artifact/Ebm35DjK8bRN1e53n3YPAA

`ComponentsDark.dc.html` and `MobileChatDark.dc.html` only mount their light twin with `theme="dark"`; the tokens live in the twin.
